# Regnum — обязательные инструкции агентам

Minecraft 1.21.1, NeoForge 21.1.x. `mod_id=regnum`, пакет `com.alkimor.regnum`. Игровой текст — по-русски; `en_us.json` должен дублировать `ru_ru.json`.

## Старт каждого шага

1. Выполнить `git status --short` и посмотреть относящийся к задаче diff.
2. Прочитать `coord/BOARD.md`, `coord/STATE.md`, свой `coord/INBOX_*.md` и `coord/LOCKS.md`.
3. Взять одну подсистему, отметить задачу `doing` и поставить lock только на реально редактируемые файлы.
4. Архитектурная карта: `coord/CODEX_PROJECT_INDEX.md`. Не читать старые LOG/IDEAS/task-документы без связи с текущей задачей.

## Работа с файлами

- Папка проекта — источник истины. Не затирать чужие или незакоммиченные изменения.
- Один агент — одна подсистема. Общие файлы и чужая полоса требуют lock и сообщения в INBOX.
- Не править вручную generated-файлы:
  - `src/main/java/com/alkimor/regnum/client/model/*`;
  - `src/main/java/com/alkimor/regnum/kingdom/CultureWeapons.java`;
  - модели, текстуры, язык, рецепты и loot, создаваемые `tools/*.py`.
- Генераторы запускать из корня: `python3 tools/gen_data.py`, `python3 tools/gen_textures.py`, `python3 tools/modelgen/run.py`.
- Ничего не удалять без явного согласования владельца. Историю координации не копировать в горячие файлы: для неё есть Git.

## Границы ответственности

- Claude: серверная логика `kingdom/`, армия/наука/шпионаж/события, `core/SelfTest.java`.
- Codex: `client/`, UI, render, generators моделей/текстур, worldgen/NBT, визуальные данжи, баланс-таблицы, `КАК_ИГРАТЬ.md`.
- Общие: `KingdomModule.java`, `RegnumCommands.java`, `CityInfoPayload`, языки через `gen_data.py`. Только по lock и с кратким handoff.

## Проверка

- `build.bat` — сборка; `build-watch.bat` — запуск по `_rebuild.flag`.
- Дополнительные флаги: `_selftest.flag`, `_clienttest.flag`, `_visualtest.flag`.
- Успех подтверждают только `EXIT_CODE=0`, `[REGNUM-SELFTEST] RESULT: OK`, `[REGNUM-VISUAL] RESULT: OK` — в зависимости от требуемого контура.
- Перед визуальным тестом при закрытой игре: `python3 _reset_visual.py`.
- Визуальный тест открывает Minecraft — запускать только с согласия пользователя.
- Сборка требует свободного `coord/BUILD.lock`; после завершения вернуть `free`.
- Финальный jar — только после одобрения владельца.

## Неподвижные продуктовые решения

- Без объявленной войны чужак не ломает и не ставит блоки во владениях от бедрока до неба; во время войны работают стены и осада.
- Армейский ИИ должен отвечать на высоту, ямы, столбы и подкопы, а не допускать простой абуз.
- Базовая сложность высокая: умные мобы, тяжёлые боссы, дефицит и долгая прокачка. Для слабых ПК сохраняются Lite/LOD-настройки.
- Не загружать client-only классы на dedicated server; не рассинхронизировать server impact, telegraph и client animation.

## Завершение шага

Обновить BOARD/STATE при изменении статуса, оставить только новое сообщение в INBOX, снять свои locks, записать короткий итог в `coord/LOG.md`, выполнить релевантную проверку и сделать отдельный понятный коммит.
