# Связь Claude <-> Codex (общая папка = канал)

Агенты не видят друг друга напрямую. Связь — только через файлы в coord/. Читать BOARD.md и свой INBOX в НАЧАЛЕ каждого шага, писать в конце.

## Файлы
- BOARD.md — задачи: id, владелец (claude|codex), статус (todo|doing|review|done), файлы, заметки.
- INBOX_claude.md / INBOX_codex.md — сообщения получателю. Только дописывать в конец: `## [дата-время] от X`, затем текст. Прочитал и учёл — пометить `(прочитано)`.
- LOCKS.md — какие файлы/каталоги сейчас заняты. Перед правкой записать строку `путь | агент | задача`, после — удалить строку. Чужой путь не править.
- BUILD.lock — содержимое `free` или `busy <агент> <время>`. Удалять файлы на ПК нельзя, поэтому только перезаписывать. Перед сборкой записать busy, после результата — free; при busy не трогать _rebuild.flag.

## Полосы (кто чем владеет)
- CLAUDE: логика королевств/армии/наука/шпионаж/деревни/события (src/.../kingdom, core/SelfTest.java), Project-доки.
- CODEX: клиент и визуал: GUI-экраны (client/screen), рендер, модели/текстуры (tools/*.py), структуры/датапаки (worldgen, структуры NBT), CAMP-данжи, баланс-таблицы, документация КАК_ИГРАТЬ.md.
- Общие файлы (KingdomModule.java, RegnumCommands.java, en/ru lang через tools/gen_data.py, CityInfoPayload): только через LOCKS.md и краткую запись в INBOX, чтобы не затирать друг друга.

## Правила
1. Одна задача — один владелец. Новую задачу берёшь, пометив `doing` в BOARD.md.
2. Нужна правка в чужой полосе — пиши в чужой INBOX, не правь сам.
3. Сборку запускает тот, кто закончил правки; перед ней положи BUILD.lock; после результата (build.log: RESULT/EXIT_CODE) удали.
4. Критерий «готово»: сборка EXIT_CODE=0 и `[REGNUM-SELFTEST] RESULT: OK`.
5. Визуальные тесты/видео открывают окно Minecraft — только по согласованию с пользователем.
6. Мелкие коммиты/бэкап: перед крупным изменением `_source_backup.zip` обновлять не нужно, если есть git; иначе копия src в _source_backup.zip.
7. Итог каждого шага — 2–3 строки в regnum/progress-log.md (Project «mode») или в coord/LOG.md.
